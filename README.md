# Body Atlas updates

Public download location for **Body Atlas** Android app updates.

This repository is for published Android installer files (APKs) and an update manifest (`latest.json`) only.

**No private medical data, app source code, signing keys, or personal records belong in this repository.** Health information stays on the user's phone inside the separate, offline Body Atlas app.

Updates are published through the private Body Atlas project's verified release workflow. The separate companion updater checks the app's package identity, trusted signing certificate, version and downloaded APK checksum before asking Android to install it.

There are no public updates available yet. The update feed and first release will be added after signing credentials and release access are configured securely.
